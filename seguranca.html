Segurança

Controles de segurança

Como a FOX trata dados de clientes e ações executadas nos sistemas da empresa.

Dados mínimos para o modelo

O modelo de linguagem recebe apenas o necessário para responder. Senhas de conexão de assinantes nunca são enviadas.

Confirmação com expiração

Toda ação que altera dados exige confirmação explícita. Pedidos não confirmados expiram automaticamente.

Escrita liberada por etapas

Novos canais começam apenas com consulta. A escrita no sistema é liberada com limite diário, auditoria e testes em cliente sentinela.

Registro de auditoria

As ações executadas ficam registradas em log de auditoria.

Segredos isolados

Chaves e credenciais ficam fora do repositório de código, com cópia de segurança criptografada. Logs do sistema são mantidos por 30 dias.

Alertas de falha

Falhas de atendimento notificam o administrador imediatamente, sem dados sensíveis na mensagem.
